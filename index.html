How the new Kallibr website fits together

The new site moves off WordPress (Kinsta) to Netlify. Course dates still come from aXcelerate, and enrolments still go through HubSpot. The difference is that the site reads aXcelerate directly, safely and read-only.

Runs on Netlify (live) Built, waiting to switch on Existing Kallibr systems (unchanged)

A visitor booking a course

  1. Opens a course page, for example Dogging (DG).
  2. The page asks the course data helper for upcoming classes.
  3. The helper reads aXcelerate and returns dates, centre, price and places left. Cancelled classes are hidden.
  4. The visitor clicks Enrol. A HubSpot form opens with the class already filled in.
